# 🧠 张超越 · 个人知识图谱 — FAE 技术支持工程师

## 这是什么？

一个**交互式个人能力知识图谱**，帮助你：
- 📊 可视化展示你的技能、项目、经历之间的关联
- 🎯 快速匹配目标岗位的能力要求
- 💼 在投递简历时，给 HR 一个直观的能力全景图

## 🚀 快速开始

1. 用浏览器打开 `index.html` 即可看到图谱
2. 按下面的说明修改 `data.json`，更新你的数据
3. 刷新页面即可看到更新后的知识图谱

> 💡 **推荐部署方式**：启用 **GitHub Pages**（Settings → Pages → Source: main branch → Save），即可获得 `https://chaoyue-zhang.github.io/chayce-myself` 的在线链接，直接附在简历上。

## ✏️ 如何更新数据

打开 `data.json`，按照以下格式修改：

### 添加/修改技能节点
```json
{
  "id": "s1",                    // 唯一ID
  "category": "skill",           // 固定为 skill
  "label": "技能名称",
  "level": 4,                    // 熟练度 1-5
  "description": "能力描述",
  "tags": ["标签1", "标签2"],
  "icon": "🔧"
}
```

### 添加/修改项目节点
```json
{
  "id": "p1",
  "category": "project",
  "label": "项目名称",
  "description": "项目描述与你的贡献",
  "highlights": ["亮点1", "亮点2"],
  "tags": ["标签"],
  "icon": "📦"
}
```

### 定义关系（边）
```json
{ "from": "s1", "to": "p1", "type": "uses", "label": "技能用于项目" }
{ "from": "p1", "to": "e1", "type": "part_of", "label": "项目属于经历" }
{ "from": "e1", "to": "e2", "type": "leads_to", "label": "职业发展" }
```
