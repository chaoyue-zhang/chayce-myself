# 🧠 张超越 · 个人能力知识图谱 — FAE 技术支持工程师

## 这是什么？

一个**深色工程风**的交互式个人能力知识图谱，作为简历配套作品集：
- 📊 以"张超越"为中心节点，辐射展示技能、项目、经历、领域、证书
- 🎯 帮助 HR 快速了解能力体系和岗位匹配度
- 🔗 展示"技能→项目→经历"的完整因果链路

## 🚀 快速部署到 GitHub Pages

### 方式一：直接部署（推荐）

1. 在 GitHub 新建仓库，如 `knowledge-graph`
2. 上传 `index.html` 和 `data.json` 到仓库根目录
3. Settings → Pages → Source 选 `main` 分支 → Save
4. 几分钟后获得链接：`https://你的用户名.github.io/knowledge-graph`

### 方式二：本地预览

由于浏览器安全策略，直接用 `file://` 打开可能无法加载 `data.json`。

推荐任选一种方式：
```bash
# Python
python -m http.server 8080

# Node.js
npx serve .

# VS Code
安装 Live Server 插件 → 右键 index.html → Open with Live Server
```

## 🖱️ 交互方式

| 操作 | 方式 |
|------|------|
| 查看详情 | 点击任意节点 → 右侧面板展示 |
| 聚焦节点 | 双击节点 |
| 拖拽移动 | 拖拽任意节点（中心根节点固定） |
| 缩放画布 | 鼠标滚轮 |
| 平移画布 | 拖拽空白区域 |
| 搜索定位 | 顶部搜索框 / `Ctrl+F` |
| 分类筛选 | 底部彩色标签 |
| 导出图片 | 点击"导出图片"按钮 |
| 重置视图 | 点击"重置视图" / 按 `Esc` |

## ✏️ 更新数据

修改 `data.json` 中的 `nodes` 和 `edges` 数组即可。节点类型：
- `person` — 中心人物
- `skill` — 技能（带 level 1-5）
- `project` — 项目（带 highlights）
- `experience` — 工作经历
- `education` — 教育背景
- `domain` — 领域知识
- `certificate` — 证书资质
